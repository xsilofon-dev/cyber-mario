# Cyber Mario 2077: Dendy Neon Odyssey

Ретро 8-бітний платформер у стилі Денді / NES із естетикою кіберпанку, написаний у єдиному файлі `index.html`.

## 🎮 Особливості:
- Класична фізика платформера Маріо: стрибки, розгін, ковзання, присідання.
- Збивання дронів-павуків зверху (Stomp).
- Вибивання блоків головою знизу: цеглини, блоки зі знаком `?`, збирання кібер-чіпів.
- Нано-гриб: перетворює на Super Cyber Mario зі збільшеним зростом та стрільбою плазмовими лазерами.
- Процедурний 8-бітний аудіо-синтезатор (Web Audio API).
- Ефект CRT-телевізора / Scanlines з можливістю перемикання.
- Сенсорні кнопки для мобільних пристроїв.
